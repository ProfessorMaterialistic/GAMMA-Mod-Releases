# Installation and updates

No 0.1.0 archive is published here. The historical Candidate r1 archive is not
the accepted wearable-only implementation and must not be used as a 0.1.0 installer.

For an existing maintained installation, close GAMMA/MO2, back up the candidate,
and update its three first-party script/UI/label files together. Retain the existing
Wearable Devices bracer compatibility adapter. Name the mod **SOTA Wearable Slots
0.1.0**, preserve its effective priority and enabled state, and verify its files
win. Keep only one copy enabled. No FOMOD selections or settings migration apply.

The bracer adapter must win over the base WD bracer script. Preserve the installed
SOTA, FIUT, icon and category-tab provider order. Disable the 3DSS attachment-strip
option only if you enabled it solely for the cancelled experiment.

To remove or roll back, close GAMMA/MO2 and disable the addon or restore its previous
files and priority. Wearable Devices continues to own your equipment and saved
state. If slots are absent, check the addon is enabled and its files win. If an
item needs a bracer, equip one first. Report device versions and the affected
inventory mode when troubleshooting; omit personal saves and settings from public reports.
