# SOTA Wearable Slots 0.1.0

A compact Bracer / Promin / Vektor equipment row styled for SOTA Inventory and FIUT.

## Status

Version **0.1.0** names the accepted r3 implementation. On 2026-10-12 the owner
confirmed appearance and general operation with an in-game screenshot. Individual
edge cases and alternate layouts remain unconfirmed. This is a public project
page; **no 0.1.0 downloadable archive is published here**.

## Features and controls

Three aligned slots follow the bag width, using SOTA's dark backgrounds and fonts.
Device titles remain visible; each slot reports Equipped, Empty or Bracer required.
Promin charge has a separate percentage and cyan bar. The row reserves 68 logical
vertical units above the inventory categories.

Click a slot to equip an owned device or unequip the worn one. Equipped device IDs
are omitted from the actor bag while spare copies remain. Wearable Devices owns
equipment, prerequisites and saves. Loot/trade/repair keep the row read-only.
There is no separate key binding or configuration menu.

Weapon attachment boxes were cancelled. This mod has no weapon selector or
attachment actions and does not require 3DSS or UTLF. Legacy script filenames
remain unchanged for existing installations.
