## Release checklist

- [ ] Inventory every exact archive member and classify original / derived / asset / dependency.
- [ ] Verify source/version and upstream author for each derived component.
- [ ] Record explicit permission or applicable license for exact inputs, not just current upstream main.
- [ ] Preserve copyright/license texts, modification notices and required attribution.
- [ ] Review applicable source-distribution obligations and combined-work licensing before selecting a package license.
- [ ] Remove or replace uncleared material; do not label uncertainty as approval.
- [ ] Finalize each mod's credits and release notes.
- [ ] Obtain specific explicit release authorization before uploading any package.
