# Install, update and rollback — 2.1.1

Install the .7z archive with MO2 into a new versioned folder. Preserve accepted
2.1.0 folders/archives and the original RC. With GAMMA saved and closed, disable
the older corresponding Light folder and enable 2.1.1 at the same relative
priority after the selected dependencies. Never enable old and new copies of
the same mod together. Preserve MCM/keybind preferences and existing saves.

Both companions work independently. When combined, use the matched 2.1.1 pair
and choose the same Native/G2X or Soy Adjustable backend in both installers.
Select Laser Settings, UTLF IR or IR Headlamp only when those dependencies are
installed. FOMOD supplies integration scripts, not complete dependency assets.
Official UTLF 1.0.2 and weapon registrations are required for UTLF output; its
core/HUD/light-pose modules must remain supplied by the framework. The Light pair
supplies its input/battery adapters and selected IR/item integrations.

Use GAMMA/MCM and required GAMMA headlamp/PDA presentation support; no engine
binaries are included. See COMPATIBILITY.md for optional versions and limits.

Rollback with GAMMA closed: disable 2.1.1 and re-enable the accepted 2.1.0 pair
at its previous priorities. Retain previous UTLF 1.0.1 as well if reverting the
dependency setup. Do not delete saves, archives or retained version folders.
