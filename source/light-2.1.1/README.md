# Light 2.1.1 corresponding source

Preferred maintained modules, transformation/artwork generators, exact necessary
inputs and retained package data for both Light 2.1.1 releases. Upstream input
files are source ingredients for these integrations, not complete dependencies.

Run `python reproduce.py` with Python 3 and Pillow installed, from a clean source
copy. It writes only local build/generated source/report paths. It never accesses
GAMMA, MO2 or private development. The ordered customize → visuals → package
pipeline verifies all 85 runtime/assets against RUNTIME-MANIFEST.json. Archives
are compressed separately with 7-Zip. No test dependency becomes a player requirement.

UTLF v1.0.2 sources are pinned to d8c89c385ece3fbfd10e50c054b4618bc3f09d38.
The accepted RC runtime is preserved except stable version labels. See included
notices, credits and modification disclosure; install gameplay dependencies separately.
